# AGENTS.md

Este repositório usa protocolo canônico de continuidade.

Antes de qualquer trabalho substantivo:

1. leia `00_SYSTEM/START_HERE.md`;
2. leia `00_SYSTEM/CHECKPOINT.md`;
3. siga a `NEXT_ACTION` exatamente como registrada, salvo instrução explícita do usuário;
4. aplique os protocolos científicos, pedagógicos e de privacidade pertinentes;
5. persista o estado real no GitHub ao final.

O chat não é fonte canônica de estado.
