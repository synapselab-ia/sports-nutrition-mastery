- canonical communication workflow is `reconstructed evidence → invariant core → calibrated claim → audience translation → drift audit → update conditions`;
- the F0.10 **invariant core** contains exactly eight objects:
  1. target;
  2. direction;
  3. magnitude;
  4. precision/CI;
  5. practical/decision threshold;
  6. certainty;
  7. applicability;
  8. inferential boundaries/update conditions;
- simplifying language may reduce jargon but must never reduce scientific uncertainty;
- `did not detect` is separate from `evidence compatible with no meaningful effect`, which is separate from formal equivalence/non-inferiority;
- point estimate + interval + practical/decision threshold must remain linked when material;
- `high certainty` does not imply a large/important effect;
- `low certainty` does not imply no effect;
- uncertainty sources are separated into bias, imprecision, inconsistency, indirectness and missing/dissemination evidence;
- directness/applicability remains separate from internal validity/RoB;
- conflicting literature is weighted by claim fit, design/bias, magnitude/precision, outcome/estimand compatibility, directness, synthesis context and certainty rather than paper counts;
- avoiding false balance does not authorize a mechanical evidence-pyramid shortcut;
- evidence statements remain separate from recommendation statements and recommendation strength;
- technical, practitioner-facing and lay-facing versions must preserve the same epistemic content;
- language-drift audit explicitly checks population expansion, lost magnitude/CI/threshold, categorical verbs, erased bias/applicability and accidental recommendation drift;
- every synthesis must state what evidence/assumption change would materially change the conclusion rather than only saying “more research is needed”.
