# START HERE — canonical resume protocol

Toda nova IA deve começar aqui.

## Startup mínimo

Leia, nesta ordem:

1. `00_SYSTEM/START_HERE.md`;
2. `00_SYSTEM/CHECKPOINT.md`;
3. `00_SYSTEM/PROJECT_SPEC.md`.

Depois abra apenas os protocolos e artefatos exigidos pela `NEXT_ACTION` atual.

## Autoridade

- GitHub é canônico; chat é descartável.
- Execute exatamente uma `NEXT_ACTION` por sessão, salvo instrução explícita do usuário.
- Não refaça trabalho concluído sem evidência de inconsistência.
- Não marque aprendizagem como domínio sem desempenho observado.
- Não transforme incerteza científica em certeza didática.
- Toda afirmação material de ciência aplicada deve ser rastreável a fonte adequada.

## Gate antes de produzir conteúdo

Para qualquer módulo de conteúdo:

1. identificar pré-requisitos;
2. definir perguntas de aprendizagem;
3. levantar fontes adequadas;
4. distinguir consenso, evidência emergente e controvérsia;
5. produzir material autossuficiente;
6. aplicar QA científico e pedagógico;
7. preparar o pacote de estudo/NotebookLM quando pertinente;
8. atualizar estado e deixar exatamente uma nova `NEXT_ACTION`.

## Fechamento

Ao terminar uma ação substantiva:

- verifique os arquivos alterados;
- atualize `00_SYSTEM/CHECKPOINT.md`;
- preserve pendências reais;
- registre apenas estado verificável;
- deixe exatamente uma `NEXT_ACTION` executável.
