# Sports Nutrition Mastery

Sistema público, longitudinal e baseado em evidências para construir domínio avançado em ciência da nutrição esportiva.

## Missão

Não é um depósito de resumos. O objetivo é aprender fundamentos, mecanismos, interpretação crítica da literatura e aplicação, mantendo cada conclusão relevante rastreável à evidência que a sustenta.

A progressão desejada é:

`fundamentos → mecanismos → evidência → crítica → aplicação → integração → domínio demonstrado`

## Fonte canônica

## Repositório público

Este repositório não deve conter dados pessoais ou de saúde identificáveis, exames, medidas corporais privadas, dieta individual, credenciais, tokens ou qualquer outro dado sensível. O acompanhamento de aprendizagem deve registrar desempenho acadêmico de forma não sensível.

## Limite de escopo

O projeto é educacional e científico. Domínio teórico não equivale a habilitação profissional nem substitui avaliação individual por profissional legalmente habilitado quando necessária.
