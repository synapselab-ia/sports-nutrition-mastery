# SOURCE REGISTRY

Registro de fontes efetivamente utilizadas pelo projeto.

## Template

```text
SOURCE-ID:
Citation:
URL/DOI:
Source type:
Publication year:
Question answered:
Population/context:
Key contribution:
Key limitations:
Claims supported/contested:
Modules using source:
Last checked: YYYY-MM-DD
```

## Regras

- não registrar fonte apenas porque apareceu em busca;
- registrar finalidade concreta;
- priorizar DOI/página oficial estável;
- evitar depender de resumo secundário quando a fonte primária/revisão está acessível;
- não versionar no GitHub público PDF sem permissão de redistribuição.
